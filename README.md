# Njangiva

> **Save. Prepare. Contribute.**

Njangiva is a modern financial preparation and savings Flutter application built to help members save gradually and stay financially ready when their Njangi contributions are due.

## Features

- **Total Savings & Active Goals Overview**: Real-time balance visibility, locked savings tracking, and goals summary.
- **Goal Management**: Create and track specific Njangi savings targets with calculated due dates and progress indicators.
- **Deposit Integration via Fapshi**: Seamless mobile money deposits supporting MTN Mobile Money and Orange Money.
- **Maturity & Payout Release System**: Timed savings locks to maintain discipline until the contribution date.
- **Responsive Multi-Platform Shell**: Optimized for Mobile, Tablet, and Web browsers.
- **Transaction Logs & Statements**: Full history of deposits, withdrawals, and platform service records with export capability.

## Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.9.0 or higher)
- Chrome (for web) / Android Studio / Xcode (for mobile)

### Installation

1. Install dependencies:
   ```bash
   flutter pub get
   ```

2. Run tests:
   ```bash
   flutter test
   ```

3. Launch application:
   ```bash
   flutter run -d chrome
   ```

4. Build for Web:
   ```bash
   flutter build web --release
   ```
